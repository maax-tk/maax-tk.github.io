This is an invocation URL.

Its job is to identify an App Clip and carry context into it. It is never rendered by the clip. You are seeing this page because you opened the URL in a browser rather than through an App Clip invocation.

This URL

For a real invocation, iOS must first agree that this domain may launch that clip. That agreement is the file at /.well-known/apple-app-site-association, which names <TeamID>.com.lotusflare.appclippoc.Clip.

The page the clip actually renders is a different URL entirely: /appclip-poc/
